入出力デバイス

入出力デバイスとはコンピューターとデータをやり取りするハードウェアで下記で触れる入出力装置や補助記憶装置などの機器を指す。

  • 入出力インターフェース
    コンピュータと入出力デバイス間のインターフェース。

  • デバイスドライバー
    デバイスにインターフェースを提供するソフトウェアのこと。

入出力の制御方式

通常はCPUを介して入出力制御を行うがそれだけでは非効率なため、次の入出力制御方式が用意されている。

  • DMA制御方式（Direct Memory Access）
    CPUが転送元、転送先、転送量などをDMAコントローラへ設定した後、DMAコントローラが入出力装置と主記憶装置の間でデータを転送する方式。

    転送中はCPUがデータを一語ずつ処理する必要がなく、CPUは別の処理を実行できる。転送完了時はDMAコントローラが割込みでCPUへ通知する構成が一般的となる。

  • チャネル制御方式
    専用ハードウェアのチャネル装置を用いたCPUと並列で動く入出力装置、主記憶装置間のデータ転送方式。

    CPUの入出力指示をチャネル装置に受信させることで、CPUとチャネルを並列処理させ、CPUの待ち時間を減らす。

  • 完了を知る方法とデータを運ぶ方法は別
    「処理が終わったかをどう知るか」と「装置とメモリの間で誰がデータを運ぶか」を分けると、方式の関係が分かりやすい。

    仕組み 主に解決すること CPUが行う仕事の例
    ポーリング 装置の状態を繰り返し調べる 状態レジスタを読む
    割込み 状態の変化を装置側から知らせる 通知を受けて必要な処理をする
    DMA データ転送をCPU以外の仕組みに任せる 転送先・長さなどの設定、完了への対応

    例えばDMAでまとまったデータを運び、終わったことを割込みで知らせる構成もある。DMAを使っても初期設定まで不要になるわけではなく、転送中にはメモリやバスの帯域も消費する。これらはすべて排他的な選択肢ではない。

入出力装置

プログラム内蔵方式の装置においては以下の入力装置、出力装置でデータの入出力を行い、補助記憶装置で記憶装置のデータを永続保存する。

下記に類似記載及び重複記載あり。
応用情報技術 - プロセッサ > プロセッサ

  • 入力装置
    外部からのデータやプログラム等を受け付けるインターフェース。

    • 例 : 入力装置の一般例

      • 直接入力系
        → キーボード、マウス、トラックボール、タブレット、タッチパネルなど。

      • 入力値変換系
        → スキャナ、OCR（Optical Character Recognition：光学文字認識）、OMR（Optical Mark Recognition：光学式マーク認識）、バーコードスキャナー、ICカードリーダー、生体認証装置 など。

  • 出力装置
    データ（結果）を外部に出力するモニターやプロジェクタなどの装置。

    • 例 : 出力装置の一般例
      → モニター、プリンター、プロジェクター、スピーカーなど。

  • OCRとOMRは何を読み取りたいかで選ぶ
    申込用紙の「氏名」に書かれた文字をデータ化したいなら、文字の形から文字コードを推定するOCRが候補になる。選択肢の丸を塗ったかどうかを集計したいなら、所定の位置のマークを読むOMRで扱える。

    OMRは文字を解釈せず位置と塗りつぶしを利用できる代わりに、用紙の形式に沿った記入が必要になる。OCRでは自由な文字を扱える一方、字形や画質による誤認識への対応が必要になる。読み取り精度だけでなく、入力する側にどの形式を求められるかも選択条件になる。

モニターの種類

以下、代表的なモニターの種類。

  • STN（Super-Twisted Nematic） 液晶モニター
    X、Y軸方向からの電圧交点の液晶を駆動させる単純マトリクス方式を採用したもの。

  • DSTN（Dual-scan STN） 液晶モニター
    上記STN液晶モニターを上下2分割し、表示速度を改善したもの。

  • TFT（Thin Film Transistor） 液晶モニター
    各画素またはサブ画素に薄膜トランジスタを配置し、画素ごとに液晶を制御するアクティブマトリクス方式の液晶モニター。

    ※ 液晶自体は発光せず、バックライトの透過量を画素ごとに制御し、カラーフィルターを用いて色を表現する。

  • 有機EL（OLED：Organic Light-Emitting Diode） モニター
    有機材料の層へ電流を流すと、注入された電子と正孔が再結合して発光する仕組みを利用したモニター。

    画素自体が発光する自発光方式で、バックライトを必要としない。液晶モニターとは発光の仕組みが異なる。

  • 黒い画面でも発光の仕組みが違う
    液晶では背面の光を各画素で通す・遮ることで明暗を作る。有機ELでは画素そのものが発光するため、黒を表示する画素の発光を止められる。

    この違いはコントラストや消費電力の傾向に関係するが、「有機ELなら常に省電力」とまではいえない。表示内容、輝度、製品の制御方式によって変わるため、同じ明るさ・同じ内容という条件をそろえて比較する必要がある。

補助記憶装置の種類

主記憶装置を補助する補助記憶装置には以下様々な種類がある。

  • 記憶媒体
    ┣ 磁気ディスク
    ┃　┣ フロッピーディスク
    ┃　┗ ハードディスク
    ┣ 光ディスク
    ┃　┣ CD
    ┃　┣ DVD
    ┃　┃　┣ DVD-ROM
    ┃　┃　┣ DVD-RAM
    ┃　┃　┗ DVD-R
    ┃　┗ Blu-ray Disc
    ┣ 半導体ディスク
    ┃　┗ フラッシュメモリ
    ┃　　┣ USBメモリ
    ┃　　┣ SDメモリ
    ┃　　┗ SSD
    ┗ 磁気テープ
    　　┗ DAT

以下、代表的な記憶媒体。

  • ハードディスク 円盤に磁性体を塗布し重ねた記憶媒体で数Tバイト程度の大容量データを格納できる。

  • CD（Compact Disc）
    ディジタル情報を記録するための記録メディアで音楽を記録する目的で開発された光ディスクの一種。
    記憶容量は最大で700Mバイト程度。

    データの編集レベルで大きく以下に分類される。

    • 編集不可
      → CD-ROM
    • 追加のみ可能
      → CD-R
    • 編集可能
      → CD-RW

  • DVD（Digital Versatile Disc）
    媒体形状や記録/読取方式はCDとほぼ同じ。
    ディジタル情報を記録するための記録メディアで映像を記録する目的で開発された光ディスクの一種。
    120mm DVDの記憶容量は片面1層で約4.7Gバイト、片面2層で約8.5Gバイト。両面2層のDVD-ROMでは約17Gバイトとなるため、層数だけでなく片面か両面かも区別。

    データの編集レベルで以下に分類される。

    • 編集不可
      → DVD-ROM
    • 追加のみ可能
      → DVD-R、DVD+R
    • 編集可能
      → DVD-RW、DVD-RAM、DVD+RW

  • BD（Blu-ray Disc）
    DVDの後継となる光ディスクで青紫色半導体レーザーを使用。
    標準的な記憶容量は1層で25Gバイト、2層で50Gバイト。多層の記録型ディスクには100Gバイトや128Gバイトのものもあるため、50GバイトがBD全体の最大容量というわけではない。

    データの編集レベルで以下に分類される。

    • 編集不可
      → BD-ROM
    • 追加のみ可能
      → BD-R
    • 編集可能
      → BD-RE

  • フラッシュメモリ 電源を切ってもデータを保持するEEPROMの一種で編集可能な半導体メモリ。

    記録媒体としてUSBメモリ、SDメモリカード、SSD（Solid State Drive）、メモリスティックなど様々な形態で用いられている。

  • DAT（Digital Audio Tape）
    DATは音声データを記録するための磁気テープ規格。コンピュータのバックアップではDATの技術を利用したDDS（Digital Data Storage）形式が用いられる。両者は関連するが、厳密には同じ名称ではない。
    DAT 72の容量は非圧縮で36Gバイト、2:1圧縮を仮定して72Gバイト。DAT 320は非圧縮で160Gバイト、2:1圧縮を仮定して320Gバイトとなる。実際の圧縮後容量はデータの性質によって変わる。

  • HDDの回転数を回転待ちの時間へ換算する
    7200 rpmのHDDは1秒に120回転し、一周には \(60/7200=1/120\) 秒、約8.33 msかかる。目的の位置が一様に分布すると仮定すれば、平均回転待ち時間はその半分の約4.17 msになる。

    読み出し時間にはこのほかにヘッドの移動時間と実際の転送時間などが加わる。小さなデータを離れた場所から何度も読むと、転送量が少なくても移動と回転待ちが繰り返される。連続読み出しの転送速度だけでは、小さなランダムアクセスの性能を判断できない理由である。SSDには機械的な回転待ちはないが、制御やフラッシュメモリへのアクセス時間は残る。

まとめ

  • 入力装置はデータをコンピュータへ取り込み、出力装置は処理結果を外部へ伝える。
  • 割込みはCPUへ処理を通知し、DMAは初期設定後のデータ転送をコントローラが進めてCPU負荷を抑える。
  • 主記憶は作業領域、補助記憶は永続保存に使う。SSDは半導体、HDDは磁気ディスクを利用し、速度や容量などの特性が異なる。
  • 割込みによる通知とDMAによる転送は組み合わせられる。記憶装置の比較では連続転送と小さなランダムアクセスを分け、待ち時間も評価する。
